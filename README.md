# antibiotic-use-and-resistance-ecdc
A data-driven analysis source for antibiotic consumption and antimicrobial resistance patterns across countries and over time (using ECDC surveillance data).

# Antimicrobial Resistance Data Analysis
## Project
Exploring the Relationship Between Antibiotic Use and Antimicrobial Resistance.

## Dataset
This project uses antimicrobial consumption and antimicrobial resistance data from the European Centre for Disease Prevention and Control (ECDC).

The dataset in this repository is a cleaned and merged version of ECDC data prepared for academic analysis.

## Data Coverage
- 27 countries
- 2013–2022
- E. coli
- Klebsiella pneumoniae
- Staphylococcus aureus

## Source
European Centre for Disease Prevention and Control (ECDC).

The original ECDC data has been cleaned and merged for this project.
